# Methodology templates

Sanitized, reusable working methods. Ships in **v0.3.0**.

Planned contents (each as a markdown template with "how to use" / "when NOT to
use"):

- Destructive-op pre-checks.
- Staged rollout for identical changes across many hosts.
- Peer-review proposal + adversarial review flow.
- Document-on-close (propagate lessons across knowledge bases).
- Severity classifier for deciding when to escalate a review.

Templates are generic by design — no organization-specific data. Placeholder
directory in the current scaffold.
